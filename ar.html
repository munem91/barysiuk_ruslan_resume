02

ما أقدّمه

تطوير Flutter مع تكاملات iOS وAndroid الأصلية: من MVP وتدقيق الكود إلى الإطلاق في المتاجر والدعم.

  • تطبيقات Flutter متعددة المنصات

    تطبيقات iOS وAndroid من قاعدة كود Dart واحدة: Clean Architecture وBLoC وRiverpod، وflavors لبناء عدة تطبيقات من الكود نفسه.

    • Flutter 3
    • Dart 3
    • BLoC
    • Riverpod
    • Clean Architecture

  • تطوير أصلي على iOS وAndroid

    Swift وSwiftUI وKotlin حين لا يكفي Flutter: Platform Channels، وحزم SDK أصلية، ونموذج أولي على watchOS، وأذونات Android 13/14.

    • Swift
    • SwiftUI
    • Kotlin
    • Platform Channels

  • الاشتراكات والمشتريات داخل التطبيق

    StoreKit 2 وGoogle Play Billing مع التحقق من جهة الخادم، وRevenueCat، وشاشات الاشتراك، واستعادة المشتريات. أتولى تمرير التطبيقات عبر مراجعة App Store.

    • StoreKit 2
    • Google Play Billing
    • RevenueCat

  • البيانات الصحية والساعات الذكية

    HealthKit (40+ نوعًا) وHealth Connect: بيانات من الساعات والهواتف، والمزامنة، وقواعد مراجعة Google Play للبيانات الصحية.

    • HealthKit
    • Health Connect
    • watchOS

  • مكالمات الفيديو والذكاء الاصطناعي

    مكالمات فيديو عبر WebRTC وLiveKit، وبث ردود LLM عبر SSE وقراءتها بصوت مسموع بتحويل النص إلى كلام.

    • WebRTC
    • LiveKit
    • LLM
    • SSE

  • الكاميرا والرؤية الحاسوبية وOCR

    حزم SDK أصلية للكاميرا، ومسح المستندات، وعدّ التكرارات عبر الكاميرا. تعلم آلي وOCR على الجهاز دون خادم مخصص: ONNX Runtime وOpenCV وTesseract.

    • ONNX Runtime
    • OpenCV
    • Tesseract OCR

  • تدقيق الكود وإنقاذ المشاريع

    أتعمق في الكود الموروث، وأوثّق البنية المعمارية، وأنجز المشاريع المتعثرة: أحدها وصل من التدقيق إلى الإطلاق في 1.5 شهر.

    • CI/CD
    • Fastlane
    • TestFlight
    • Jira / Linear

  • تطوير قائم على الذكاء الاصطناعي

    أستخدم Claude Code وCursor يوميًا منذ 1.5 سنة: خطوط عمل بالوكلاء مع وكيل مراجعة، وFigma MCP. وعبر Dart MCP أزلت 2,000+ إعادة بناء غير ضرورية للودجات.

    • Claude Code
    • Cursor
    • MCP
